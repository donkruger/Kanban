# Kanban Pro

A local-first, filesystem-backed Kanban board for macOS. Your boards live as Markdown files on disk — fully portable, AI-agent readable, no vendor lock-in.

## Download

| Mac Type | Download |
|----------|----------|
| **Apple Silicon** (M1 / M2 / M3 / M4) | [Kanban Pro — arm64.dmg](https://github.com/donkruger/Kanban/releases/latest) |
| **Intel Mac** | [Kanban Pro — x64.dmg](https://github.com/donkruger/Kanban/releases/latest) |

Go to the [Releases](https://github.com/donkruger/Kanban/releases) page and download the DMG for your architecture.

Both DMGs are **signed and notarized** with Apple Developer ID. On first launch, macOS may show a verification dialog — click **Open** to proceed.

## About Early Access

We built Kanban Pro for the Mac App Store. A macOS 26 platform bug currently blocks all Electron apps from launching under App Sandbox on ARM64 — we've spent 40+ hours documenting the full technical saga and filed upstream with Apple, Chromium/V8, and the Electron team.

While we wait for the fix, **early access is free**. When it ships on MAS, it will be $14.99.

- [Upstream Chromium issue](https://issues.chromium.org/issues/499332110)
