# Security Policy

## Supported Versions

The latest early-access release of Kanban Pro (published on this repository's Releases page) receives security fixes. Older early-access builds are not patched; please update to the latest release.

| Version | Supported |
| ------- | --------- |
| Latest early-access release | Yes |
| Older early-access releases | No — please update |

## Reporting a Vulnerability

Please report security issues privately. Do **not** open a public GitHub issue for a vulnerability.

**Preferred:** use GitHub's private vulnerability reporting for this repository — open the **Security** tab and choose **Report a vulnerability**.

**Email fallback:** security@goodguyapps.com

Please include:

- A clear description of the issue and its impact
- Steps to reproduce, or a proof of concept if available
- Affected version(s) and platform (macOS / Windows), if known

## Response

We aim to acknowledge reports within **5 business days** and to share an initial assessment or remediation plan when we have one. Coordinated disclosure is appreciated; we will work with you on timing before any public discussion of the issue.

Thank you for helping keep Kanban Pro users safe.
